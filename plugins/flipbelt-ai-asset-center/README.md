# 飞比特 AI 成果助手

版本：0.1.0。一个插件包含登记器和孵化器两项技能，连接器作为独立授权依赖。先从真实工作机会形成方案，或直接把已有成果整理为简明成果卡；默认保留本地草稿。

| 场景 | 技能 | 示例 |
| --- | --- | --- |
| 已有成果整理、AI 形成过程回顾、登记 | flipbelt-ai-asset-registrar | 帮我整理当前项目的成果卡，先保存本地草稿。 |
| 反复返工、需求探索、方案与交接 | flipbelt-ai-workflow-incubator | 帮我梳理这项重复工作，给出可试方案。 |

在宿主技能菜单或对话提及中选择对应技能。两项技能职责独立；形成成果后仅在用户选择登记时交接。没有文件能力时交付可复制文本，没有连接器时继续本地模式。

需要组织保存时先读 [连接器配置](CONNECTORS.md)。现有连接器是 Windows 本机 stdio MCP，需 Python 和 uv；依赖安装、本人授权及企业访问策略分别配置。套件上传不会创建服务、安装依赖、授予业务权限或替本人确认。

本 Codex 市场包保持技能与连接说明，不捆绑 MCP 配置，不复用知识库 App。Windows 本机连接器可从同次千问办公分发 ZIP 提取 `connector/`，配置步骤见 CONNECTORS.md；未配置时保持本地模式。团队云端使用仍需真实资产 App 或远程 MCP 适配。

正式模式只保存用户授权的必要摘要；身份、类型和权限以服务端为准。每次变更保留 request_id，网络结果未知先查询回执。草稿私有，最终登记由本人打开 confirmation_url 核对确切版本并确认；待审核与真实业务验收分别报告。

三种分发均来自同一项目源并带 `SOURCE-PROVENANCE.json`。安装成功、16工具发现、本人授权和真实登记闭环是四项独立证据，不能互相代替。企业环境尚需人工导入和代表性任务验收。
