# 飞比特知识库编辑部团队分发

版本 `1.0.0`，包含总编、产品、尺码、扩展知识、专栏、关系台、独立审校和交付八项技能。安装后新建聊天，以编辑部入口说明目标知识、来源材料及期望交付。

## 使用条件

- 每位员工独立连接已有 FlipBelt Knowledge App，知识读取仍受本人权限限制。
- 云端可依据当前知识和用户提供的原稿制作修改单、草稿、关系报告及审校材料。相关工具或来源不可用时明确缺口，不推断产品事实。
- 本地文件编辑、Schema/Audit/Preview 与 HTML 平台校验需要真实工作区和工具；缺依赖时交付可审阅材料，不能声称完成本地写入或验证。
- 独立审校需要只读独立 Agent 或指定复核人。作者自查、插件安装及自动检查均不等于人工验收。
- 只读 App 不写 Revision 或激活 Release。正式内容仍由有权限的管理员使用现有平台流程发布。

## 维护来源

唯一领域规则维护源为既有个人编辑部插件；本仓是团队下游分发。八项 `SKILL.md`、领域政策、审校表、模板和图标按源文件复制。团队适配仅覆盖工作区发现、App 读取、检查/交付、历史资料与术语查询入口；不分发内部词库、旧 release 快照、本机路径或远程 HTTP helper。

`SOURCE-PROVENANCE.json` 记录完整源快照摘要、逐文件来源与复制/适配清单。团队适配文件在这里维护；领域规则须先改唯一维护源，不能直接在下游扩展。

更新时从市场仓库根运行：

```powershell
python -X utf8 scripts/sync_editorial.py --source <已确认的个人编辑部插件根目录>
python -X utf8 scripts/sync_editorial.py --source <已确认的个人编辑部插件根目录> --check
python -X utf8 scripts/validate_marketplace.py
```

同步不修改源、不访问网络、不删除文件，也不提交或发布。团队适配的源文件变化会阻断同步，先比较当前源与已审阅适配，再按新的实际版本更新来源记录。发布前审阅差异并运行技能校验和原生市场读取。
