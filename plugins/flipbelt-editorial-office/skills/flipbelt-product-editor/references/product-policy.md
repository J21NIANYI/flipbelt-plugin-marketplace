# 产品来源与表达
## 来源
当前用户明确修正优先，其后是当季结构化资料/检测报告、已确认 V2 对象、未被替代的历史资料。逐项记录产品、季节、分支、部位、方法、条件和证据；冲突不能裁决时只停止冲突事实。
公开资料不能补成分、克重、颜色、规格、口袋、结构、品牌配置、温区或产品性能；通用百科由扩展编辑研究。本地资料只证明其适用对象。
## 产品页结构基线（26FW 优先）
- 新建、全量改稿或核验产品稿时，先通过已授权的只读知识接口对照当前已发布的 26FW 同类产品页，记录 release、样页与板块顺序。已有页面按用户范围处理。线上读取不可用时，用可追溯的 26FW 本地镜像并说明范围；不能用 Markdown 可解析代替平台结构核验。
- 27SS 产品稿沿用当前 26FW 九个正文板块及顺序：产品基础画像 → 目标人群与适用场景 → 核心功能系统 → 面料基础信息 → 面料性能 → 面料原理与应用 → 辅料与细节工艺 → 差异化设计 → 差异化对比。标题层级与对应样页一致。面料、分支或检测指标的细分在所属板块内用小标题、列表或表格组织，不另增同级板块。产品 Header 仍独立维护，成衣规格归同款 Size Guide。26SS 同款用于事实沿革，不优先作为格式样板。
- 核心功能系统必须正好三条一级功能项。每条使用「结构/配置」「解决痛点」「用户感知/使用价值」三个下级项，分别交代真实配置、对应的运动问题和具体使用价值。有依据时在相关项补原理或适用条件。归并相近卖点，将反光、配件、工艺等细节放回对应板块，保留已核实的事实。支撑不足时在审查记录中标明缺口，草稿不得按通过交付。不拆词、搬用旧参数或写正文待办凑数。
- 逐项核对当季来源中可用的分支、使用场景、面料部位、结构、工艺和对比信息，在审查记录中保留来源与适用对象，并核对每个有依据的独有事实是否进入相应板块，避免把产品页压成简介。无数据时用有依据的定性表述；不得补造温区、成分、重量、工艺参数、配置或效果。
- 没有真实且获授权的图片时，正文不写「正文图片」、示意图清单、假链接或空图块。V2 页面 assets 使用空数组。图片需求只记入任务记录或素材 Tracking。

## 产品基础画像与目标人群的固定格式
两节先后固定，以下编号仅表示顺序。产品正文使用一级无序列表，字段名后用全角冒号。有分支、痛点明细或不同使用条件时，在对应字段下缩进列项。单一说明可与字段名同一行。V2 沿用现有产品画像和场景 Section 类型及稳定 ID，字段名属于 Markdown 正文。

### 产品基础画像

1. **产品定义**。一句说明产品是什么，包括品类、主要用途和区别性结构。
2. **产品地位**。当季确认的字段按「新品或旧升级 → SABC 分级 → T 层级 → 市场角色」排列。承担的产品线任务可另作下级项。只有定性角色时，直接写有证据的系列分工或产品任务。按下方规则确定跨季分级。
3. **款式区分**。说明适用性别及有效分支，分项写版型、覆盖范围或关键配置的实际区别。单一款也要说明形态，保留正式款名。
4. **定位**。写为谁设计、解决什么使用问题以及主要价值。
5. **整衣自测重量**。仅在编辑范围允许且有当季实测时作为末项，注明款式、样衣尺码与重量。暂略成衣规格或整衣重量的交付省略此项。

### 跨季分级确认

- 核对当季已确认的分级。为 27SS 拟定分级时，优先查询 26SS 同款已发布页；同系列分支须核对是否共用分级。前代等级作为延续建议，按当季 SABC 和 T 层级口径表达。
- 逐款列「前代基线 → 当季建议」，在同一轮对话中集中标出新品、只有近似前代、双档、口径换档和资料冲突。用户可整表确认，或在约定其余按表的前提下只回复变更项。单款明确决定优先，已确认的款无需重复确认。
- 审查记录保留季节、款式、前代页面及当季确认依据。正文写最终等级和实际角色。未获确认的建议、企划占位和款色评分保留在审查记录。

### 目标人群与适用场景

1. **目标人群**。写面向哪些跑者或实际使用者。合并款按适用分支区分。
2. **人群特征**。写训练习惯、装备需求或体感偏好。有据才写配速、跑量或完赛时间。
3. **核心痛点**。使用下级列表，每项写短痛点名和具体触发或表现。可按当前产品归并，三条的硬限制只用于后面的「核心功能系统」。
4. **适用场景**。列训练、比赛或日常使用情境。多分支有不同用途时分别说明。
5. **适用温度与体感**。使用下级列表，每项以使用条件起头，写该条件下的穿着体验或搭配。有当季证据才写数值温区；无温区时采用有证据的高汗、迎风、动态跑动或静态停留等条件。仅保留与本款相关的分项；证据连定性体感也不足时省略该项，缺口记在审查记录。确有当季依据的叠穿指南可置于本节末尾的小标题下。

## 正文组织
产品 Header 保存定位、颜色/图案和波段。颜色 launch_wave 仅有受控事实时填写；未知则不写占位或伪分组，进入 Tracking。
Section 说明场景、具体材料应用、结构、工艺、差异与使用价值。不得创建 product_profile、general_brand_knowledge、color_launch_wave、visual_assets 或口袋参数 Section。
合并款在所有相关叙述/表格明确分支，不能互搬事实。款式对比必须有直接选择或替代关系，不能跨部位/任务凑对比。
面料与辅料分别说明实际应用；辅料可按结构、原理、体验组织，不能为形式补造原理。
已存在的通用主题首次建立可打开的 Reference；“产品可被引用”不授权删去产品专属功能、工艺或体验。
正文不用 Who、Scenario、Temperature Guide、已确认参数、表达边界、见首次 Knowledge Reference 等框架词；不显示内部 Tracking ID。
口袋数量、尺寸、推荐尺码留在同产品 Size Guide；产品页保留引导与真实引用。缺目标先登记依赖，不构造悬空链接。
## 检测与体感
面料基础信息与性能信息分层呈现；按下节规则将已有性能参数、原理与性能组织为独立 Section，再按吸湿速干、透气/透湿、弹性/回复、保暖/热阻、耐用性等实际特点分组。合规、色牢度不与异质指标混放；已有受控成分时置于各面料基础信息的首行，不置于性能数据之后。
吸湿速干按实际报告逐项保留：浸湿时间、吸水速率、最大浸湿半径、液态水扩散速度，以及有来源的吸水率、滴水扩散时间、芯吸高度、蒸发速率等，不凭此列表补报告缺项。洗前/洗后、浸水面/渗透面、部位、洗涤次数与测试条件紧邻数值。抑菌数据保留对应菌种、洗涤次数、抑菌率及有依据的等级。不用送检样颜色、报告编号、“无判定阈值实测”集合项混放异质指标。
有直接可比基准才描述基准→对比→变化幅度；无阈值只报告实测，不称达标。局部结果不扩成整衣。
温度/体感适用时集中说明有来源支持的动态/静态差异和相关条件，不凭空生成核心区、上下限或医学模块；已确认知识不因缺量化证据新增不确定性板块。
## 跨季与维护
先判断当季升级、取消或延续证据。未被替代历史设计可按仓库规则作为历史来源使用，明确季节及 provenance.previous_season_basis；当季未提及不自动证明保留。跨款/跨季性能数值不能无证据搬用。
材料/测试缺口变动同步 _tracking/材料与测试缺口总表.md；视觉缺口同步 _tracking/视觉素材缺口总表.md。实际位置先核对，未知结构不擅造 Tracking 契约。
历史常量仅作为查找线索，尤其腰头层数、反光位置、材料品牌、口袋数、裁剪尺寸和季节专有技术须重新对照当前产品事实。

## 面料基础信息与性能分层（2026-09-22）
1. 写作前逐面料核对已有受控资料与页面实际呈现。来源已完整且适用范围明确的成分、克重、层次、部位及性能不得仅留在原始资料或内部记录中；正文应完整承接。缺项不补造，冲突只暂停相关事实，不删除其他已确认信息。
2. 成分已核实时，置于对应面料小节或信息组的首条正文信息。之后按产品特点列出面料名称、实际应用部位、层次、克重和必要结构信息；不要机械凑齐固定字段。标称成分与实测成分明确区分，用户确认使用标称值时采用对应标称口径，不把检测偏差改写为标称配方。
3. 多层方案分别描述外层、里料、中间填充层及局部拼接材料。各层独立标注其成分、克重、部位和作用，不能把里料成分挂在“大身复合面料”之下造成整套面料同成分的误读；不把局部排湿材料默认作整件里料。只写已确认层次与覆盖部位，不从参考图中其他款式的部位推断本款。
4. 基础面料单元保持简洁，性能参数、形成原理与性能进入独立的“面料性能”等主题单元，并明确关联面料、层次和部位；成分、克重等基础规格仍留在基础信息。优先保留或重用已有稳定 Section ID；拆分时逐项迁移完整事实与条件，新增内容使用新 ID，核对所有原有引用，不机械重建整页。
5. 性能单元采用统一的信息顺序：对应面料及部位 → 性能项目 → 有依据的数值/单位与测试条件 → 原理与使用意义。无量化数据时只呈现已有定性性能和机制，不填空表或虚构参数；适用限定紧邻结论。表格、列表或现有组件仅在当前 Schema 与渲染器支持且有助理解时使用，不发明组件或为组件改契约。
6. 同材料方案跨款核对遗漏：确认季度、分支、材料规格、层次、应用部位及证据适用范围，不能仅因同品牌或同系列就复制参数。已确认共用且检测明确针对该材料的结果，可补到相关产品对应部位，并标明材料级结果；整衣测试、不同试样或适用范围不明的数字不可移用。数据不足不阻止已证实的材料基础信息和定性性能呈现。
7. 本轮具体产品确认只作为对应受控产品事实维护，不写成全库固定配方或默认部位；新季度/新分支仍按来源规则重新核对。页面标题与 Section 标题遵循共同约束的短标题规则。
