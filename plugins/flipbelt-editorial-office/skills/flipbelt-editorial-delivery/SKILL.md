# 飞比特编辑交付

先读 [共同约束](../flipbelt-editorial-chief/references/workspace-contract.md)，随后按 [交付流程](references/delivery-policy.md) 选择修改单、本地变更或现有回流。
交付应包括用户可审阅的变更、实际检查、引用缺口、独立审校结果和下一步；不重复生成多种文件格式。
本 Skill 不授予提交、推送、生产发布或钉钉同步权限。
动态 HTML 交付按 [真实发布流程](references/html-publishing.md) 提供可上传单篇文件、校验结果、版本基线与回滚材料。由用户执行现有管理员上传/草稿/发布；仅据实际回执报告 Revision 或 Release 状态。

## 本地统一入口
涉及本地编辑、检查或 Revision 交付时，读取 [fbkb 操作契约](../flipbelt-editorial-chief/references/knowledge-operations.md)；遵循本职责的自动检查与授权边界。
