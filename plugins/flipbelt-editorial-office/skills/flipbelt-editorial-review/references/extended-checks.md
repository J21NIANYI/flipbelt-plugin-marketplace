# 扩展检查
- 页面/小节标题是否简洁、可检索，避免长句标题；标准编号、技术正式名称与消歧是否保留，解释与适用限定是否完整移入正文，稳定 ID 与引用是否保持有效。
- 写作意图明确，逐 claim 研究日期/来源/适用范围充分；纯关系调整不强制研究。
- 标准有官方版本/状态，品牌技术有官方主体；机制、效果、比较与剂量有相应证据。
- 本地产品不认证通用结论；示例完整读取并锁定所用基线，线上例子同 release。
- 必要信息槽覆盖，推荐字数不是门槛，不为压字数删条件；数量不能代替深度。
- 九类主目录、canonical、negative aliases、关系和终审范围符合领域与关系台规则。
- 没写产品、尺码或内部品牌事实；研究不足仅 Tracking。
- 参考 [扩展入口](../../flipbelt-extended-editor/SKILL.md) 与 [关系规则](../../flipbelt-reference-desk/references/relations.md)，不在此复制词库。
