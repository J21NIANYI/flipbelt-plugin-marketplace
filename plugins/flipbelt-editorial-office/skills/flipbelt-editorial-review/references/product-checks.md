# 产品与品牌检查
- 已有完整且适用的面料资料是否在正文呈现；每种面料成分是否首行，标称/实测口径是否清楚。
- 外层、里料、填充和局部拼接是否分开；成分、克重、部位、作用是否归属正确，未从其他产品参考图搬用部位。
- 基础信息是否简洁；参数、原理与性能是否有独立且关联清楚的单元，数值/单位/条件是否齐全，组件是否受当前契约支持；拆分后稳定 ID、事实、引用是否保留。
- 同材料方案是否有遗漏；跨款参数是否具有材料规格及证据适用范围支持，未把材料或局部测试扩成整衣结果。
- 标题是否为简短主题；从长标题迁出的解释及限定是否完整保留在正文。
- 每个新增事实有允许的来源、季度/分支/部位，产品专属事实未从公开资料补造。
- 产品仍能解释定位、场景、功能、使用与直接选择差异；未被模板框架、检测目录或过量边界声明替代。
- Header 与 Section 分工正确，未知波段不伪分组；颜色不混入尺码，口袋参数不留产品页。
- 性能按价值分类，方法/洗前后/部位随数据；不以合规材料身份替代性能，不反推未知基准，不把局部当整件。
- 跨季历史未被当季新事实，未越权沿用历史性能；实际工艺与体验未被通用 Reference 删除。
- 品牌模式仅受控内部事实、定义/分层/应用；真实品牌背书不附采购关系。
- 检查缺口 Tracking、last_reviewed、ID 与索引联动；局部缺测试不降级整页已确认事实。
- [产品规则](../../flipbelt-product-editor/references/product-policy.md) 是领域写作真源；本清单仅列审查问题。
