# 产品与品牌检查
- 产品稿是否对照当前已发布的 26FW 同类页面；27SS 九个正文板块的名称、顺序、标题层级与产品规则一致。记录所用 release/样页，无法在线读取时注明实际基线。
- 产品基础画像是否逐项符合「产品定义 → 产品地位 → 款式区分 → 定位」，且同级字段名一致。允许的当季整衣自测重量仅列于末尾。核对产品地位的品类分工、新品或旧升级、SABC、T 级和市场角色是否分别有当季依据；缺正式定级时检查定性角色依据。
- 跨季等级是否核对同款前代和当季口径。检查 27SS 建议是否优先参考 26SS 已发布页，新增、近似前代、双档及冲突是否已确认。逐款核对确认后的 SABC 与 T 级，用户单款决定优先于延续建议。
- 目标人群与适用场景是否按「目标人群 → 人群特征 → 核心痛点 → 适用场景 → 适用温度与体感」检查。痛点和体感条件应为下级项。温区及人群数字须可追溯，体感证据不足的例外单列审查记录。检查每篇实际层级，字段缺失（规则允许的例外除外）、错序、误用或占位须修订。
- 核心功能是否恰好三条一级项，每条是否具备「结构/配置」「解决痛点」「用户感知/使用价值」三个下级项，且能追溯到当前款的配置和适用场景。全量审查须逐篇计数；条数、板块或图片占位不符即需修订。
- 无真实图片时正文是否省略图片标注、假链接与素材需求，V2 assets 是否为空。检查真实图片的资产 ID、授权与 alt_text。
- 是否逐篇保留当季来源中已确认的产品差异与使用场景，避免以摘要、规格占位或旧季断言充当信息量。Markdown 可解析与正式 V2 结构/发布验证分开记录。
- 已有完整且适用的面料资料是否在正文呈现；已核实的面料成分是否置于对应小节首行，标称/实测口径是否清楚。
- 外层、里料、填充和局部拼接是否分开；成分、克重、部位、作用是否归属正确，未从其他产品参考图搬用部位。
- 基础信息是否简洁；参数、原理与性能是否有独立且关联清楚的单元，数值/单位/条件是否齐全，组件是否受当前契约支持；拆分后稳定 ID、事实、引用是否保留。
- 同材料方案是否有遗漏；跨款参数是否具有材料规格及证据适用范围支持，未把材料或局部测试扩成整衣结果。
- 标题是否为简短主题；从长标题迁出的解释及限定是否完整保留在正文。
- 每个新增事实有允许的来源、季度/分支/部位，产品专属事实未从公开资料补造。
- 产品仍能解释定位、场景、功能、使用与直接选择差异；未被模板框架、检测目录或过量边界声明替代。
- Header 与 Section 分工正确，未知波段不伪分组；颜色不混入尺码，口袋参数不留产品页。
- 性能按价值分类，方法/洗前后/部位随数据；不以合规材料身份替代性能，不反推未知基准，不把局部当整件。
- 跨季历史未被当季新事实，未越权沿用历史性能；实际工艺与体验未被通用 Reference 删除。
- 品牌模式仅受控内部事实、定义/分层/应用；真实品牌背书不附采购关系。
- 检查缺口 Tracking、last_reviewed、ID 与索引联动；局部缺测试不降级整页已确认事实。
- [产品规则](../../flipbelt-product-editor/references/product-policy.md) 是领域写作真源；本清单仅列审查问题。
