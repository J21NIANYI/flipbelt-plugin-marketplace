# 尺码检查
- 同季同产品同分支 raw 来源与每个数值/单位匹配，不跨款补数。
- V2 下装四 Section、非下装三 Section，顺序符合当前 Schema。
- 精简表围度换算依据明确：半围乘 2，全围不重乘，直量不乘；完整规格保持原口径。
- 男女/款式分表，行列、区间端点、国内/美码对应与来源一致；不推导未经确认推荐。
- 口袋 ×1/×2 分仓含义、宽×高直量和数量一致；— 不表示 0，整表缺资料为局部 pending_content。
- 不发布公差、工厂测法或内部定位；不在产品页新增尺寸。
- 人工逐表核对，不以正则或 Schema 通过当作数值正确。详见 [尺码规则](../../flipbelt-size-editor/references/size-policy.md)。
