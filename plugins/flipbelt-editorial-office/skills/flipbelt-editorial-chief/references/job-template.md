# 内部编辑任务
本模板仅用于 L2–L4 多步骤工作，保存在内部任务日志，不进入 content/v2/full 或知识 release。
- job_id / 日期 / Codex task ID：
- 用户目标、来源限制、允许动作、明确排除项：
- L1–L4 / T0–T3 与原因：
- 工作区 / Git commit / git status 摘要：
- 目标路径 / Page、Entity、Section ID / 编辑前 SHA-256：
- 对象所有者 / 依赖先后 / 已有用户改动：
- 事实—来源—适用产品/部位/条件—冲突映射：
- 候选与关系变化：
- 编辑后 SHA-256 / 实际变更：
- 自查、独立审校者、结果、复核所针对的哈希：
- 实际命令、结果与未执行检查：
- 交付状态 / 阻断项 / 下一步：
开始编辑前再次检查目标哈希；发生外部变化时重读并重新核对差异，不覆盖。审校后文件变化使该文件审校过期。
