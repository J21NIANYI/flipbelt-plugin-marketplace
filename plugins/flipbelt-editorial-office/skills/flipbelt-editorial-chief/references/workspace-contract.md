# 工作区与共同约束
## 执行上下文
团队版先确认执行环境和用户交付目标。读取当前已连接 FlipBelt Knowledge 的 search_flipbelt_kb、get_flipbelt_page 及所需 get_flipbelt_asset，锁定同一活动 release 和目标对象；这些工具保持只读，不能当作编辑 API。每位员工独立授权，401/403、不可用或来源缺失时停止相关事实路径，不用网络或模型记忆补产品事实。
云端可基于当前知识和用户原稿制作修改单、草稿与审校材料。只有用户明确授权本地文件编辑且真实知识工作区可访问时，才读取其根 AGENTS.md、README.md、相关配置和目标对象，运行 git status --short，保护已有改动；不猜本机路径。缺工作区只阻断文件写入、Schema/CLI 检查，不阻断有证据的可审阅材料。编辑前说明拟修改文件和 3–6 条动作。
本地编辑时，实际仓库规则和 schemas/v2/knowledge-content.schema.json 为当前权威；云端缺 Schema 时不宣称生成对象通过机器校验。若机器契约与文档对同一写入要求不兼容，停止该变更并报告，不能绕过 Schema 或擅改契约。
本共享文档由 Chief 维护，其余 Skill 只引用。新任务必须加载本文件；同任务已读且未变化时不重复加载。

## 正式层与逐页写入
本地完整知识主库为 content/v2/full；员工当前内容以线上活动 release 为准，本地文件不自动等于已发布原文。目标架构中 GitHub 保存软件与治理文件；实际来源策略及迁移进度必须实时核对，不能由目标架构推断已完成切换。representative 与 tests/fixtures 只作测试。raw 只读，_tracking/_data/_archive 为内部层。不得将内部层打包为知识 release。
Page 正文必须逐文档定位、核对来源与语义、分别编辑；多页请求不授权脚本、循环、批量替换或生成器写正文。工具仅可盘点、审计、生成不写回正文的材料或执行确定性验证。
V1 archive 不改写；只有显式历史追溯任务读取历史规则。迁移/重构先有逐知识项保留映射，真实目标存在才迁出通用知识；不删除产品专属事实或先摘要压缩再计划补回。

## 通用内容与隐私
短标题改写时，正文已完整包含的原意无需重复追加；逐项确认条件与结论未丢失即可。
页面标题和 Section 标题使用简洁、可检索的主题词或短语；扩展知识尤其避免把完整结论句、条件句、提问或多分句解释作为标题。将原标题中的机制、适用条件、限定与结论移入对应正文，保留信息，不为缩短标题删事实。保留标准编号、正式技术名称及必要消歧；不设机械字数上限。仅改显示标题时保留稳定 ID，按维护规则核对索引和引用，不以标题修订为由迁移文件或重建对象。
优先解释是什么、为谁、解决什么、如何使用与差异。表达克制，不写聊天、会议、编辑控制语句，不用删除线或空值占位伪装缺口。
已确认的结构、材料、应用与体验正常表达；没有量化检测不等于这些事实失效。条件紧邻相关结论，不堆重复宣传/医学边界模块。
正式对象不得包含报告编号、Windows 绝对路径、内部目录路径、供应商/工厂关系、采购价格、MOQ、内部编码、辅料型号或沟通记录。内部证据位置仅留内部任务/Tracking。品牌公开技术事实与供应商交易事实严格区分。
模型不得由材料、局部样品或品牌宣称推导整件产品实测。无阈值不能称达标；没有完整基准不反推绝对值。
[共享 V2 语义](v2-contract.md) 规定状态与来源；字段定义始终读知识仓 Schema。

## 维护与执行边界
实际复核后更新 last_reviewed，按既有契约维护 content_version；保留稳定 ID。新增、删除或更名 Page 同步 index.md、agent-index.md 和必要映射。
共享 Entity 变更必须盘点引用它的对象，锁定责任与影响；不要把单个参数的小改误当无风险。
提交、推送、发布、同步必须有该动作的明确授权；编辑任务本身不授予这些权限。交付流程见 ../../flipbelt-editorial-delivery/SKILL.md。
共享文件缺失或同名入口歧义时输出 BLOCKED、具体路径及恢复动作，不改用旧规则。

## 生产基线与编辑路径
涉及当前线上内容、交付路径或发布材料时，先读 [生产契约](production-contract.md)。只读核对 ready 与应用 release-meta，并以应用精确提交的文档和代码确认能力；旧 checkout、历史 TODO 或插件日期不能覆盖生产实测。纯本地任务不强制网络依赖，但不能声明其与线上一致。
本地与线上目标内容出现差异时先逐页对账，保留线上修订，不直接用旧本地页面覆盖。MCP 只读工具不是 Content API 写入工具。

## 本机 CLI 接入
已授权本地编辑后自动执行 [fbkb 操作契约](knowledge-operations.md) 的基线保留、校验、预览与差异；JSON 本地检查不要求生产连接。远程 Revision 提交单独授权，插件不授予生产启用或 Release 激活权限。
