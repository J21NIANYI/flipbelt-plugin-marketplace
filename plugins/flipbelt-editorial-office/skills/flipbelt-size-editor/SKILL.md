# 飞比特尺码编辑

先读取 [共同约束](../flipbelt-editorial-chief/references/workspace-contract.md)、[V2 语义](../flipbelt-editorial-chief/references/v2-contract.md) 与 [尺码规则](references/size-policy.md)。
1. 确认季度、产品、男女/款式分支及既有 size_guide。定位 raw/规格尺寸 的对应资料，记录原始测量口径。
2. 逐测量点核对来源与单位，按固定 V2 顺序分别维护四类内容；上装仅三类。精简表与完整规格不可共用未经换算的数值。
3. 涉及口袋关联先读 [关系台](../flipbelt-reference-desk/SKILL.md)。本编辑只写 Size Guide 和自身实体/引用，不修改产品 Header 或产品正文。
4. 执行 [尺码检查](../flipbelt-editorial-review/references/size-checks.md)，交审校与交付。来源缺失保留明确局部状态，不编造选码建议。
历史推荐表仅经 [历史入口](../flipbelt-product-editor/references/history-routing.md) 追溯，不能默认套给所有产品。

## 本地统一入口
涉及本地编辑、检查或 Revision 交付时，读取 [fbkb 操作契约](../flipbelt-editorial-chief/references/knowledge-operations.md)；遵循本职责的自动检查与授权边界。
