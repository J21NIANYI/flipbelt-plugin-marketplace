# 尺码规则
## 来源与口径
完整规格只来自 raw/规格尺寸 中同季同产品同分支的有效成衣资料。产品页、相似款、网络和历史 Skill 常量不能反推完整尺寸。
保留所有可公开且已确认的测量点及完整规格原始口径；公差、生产编码、工艺定位、供应和采购信息不发布。
## V2 顺序
1. detail_summary / 详情页精简版 / ordinal 0
2. size_recommendation / 身高体重推荐 / ordinal 1
3. complete_specifications / 完整规格尺寸单 / ordinal 2
4. pocket_partition / 口袋分区（仅下装） / ordinal 3
是否属于下装按当前 Schema 条件核对，不凭标题判断；非下装不得追加空口袋板块。
## 详情精简版
每个已确认尺码一行，首列尺码，男女/款式分支分别成表。复用当前消费者表：有确认号型时保留号型，尺码按现有国内/美码组合展示；测量字段最多五项，不因此隐藏已确认尺码行。依据当前知识仓 tests/test_kb_size_recommendations.py 的精简表契约；后续契约变化须重新核对。所有“围”字段为成衣全围；只有明确原资料为半围/1⁄2/平铺围度宽时乘 2，已全围不再翻倍，口径不明先列缺口。
长度、高度、宽度、直量不换算。精简版表头说明不含半围、1/2、平铺、工厂测法或公差；完整规格仍保留原始可公开测量口径。
## 推荐表
只使用该产品已确认推荐关系，保持男女、上下装、国内/美码对应和身高体重区间；不得由成衣尺寸自行推导推荐，也不把旧通用表复制到新款。
区间端点、留空组合、特殊体型说明均按来源，不能修补旧表区间空档或擅自扩展适用人群。无可靠推荐依据只将对应 Section 设 pending_content。
## 下装口袋
逐尺码表头：尺码 | 口袋总数 | 前中腰袋宽 | 两侧腰袋宽（单侧分仓） | 后中腰袋宽 | 大腿/侧向储物袋（宽×高）。
男女/款式分支分表。×1/×2 表示单侧分仓数；宽×高是直量，不按围度乘 2。数量与测量点只取对应资料。
有来源的表内单个无数据项可用 — 表示未提供，不代表 0；整板块缺来源用 pending_content，不写旧方括号标签或跨款补数。
产品页若仍含逐尺码参数，记录跨对象任务交 product-editor，未明确授权不顺手迁移。
