# 飞比特知识关系台

先读 [共同约束](../flipbelt-editorial-chief/references/workspace-contract.md)、[V2 语义](../flipbelt-editorial-chief/references/v2-contract.md)，再读 [关系规则](references/relations.md)。
涉及术语识别时按 [词库索引](references/term-library.md) 只读目标分类。词库是检索快照，当前对象和 Tracking 优先；无命中也不证明新实体应发布。
检查目标 Page/Section/Entity 及一跳必要依赖；只有显式全库扫描才扩大范围。输出 [关系报告](references/report-template.md)。
本台维护关系判断，不取得所有 Page 的写权限。修复源 Reference 由源 Page 编辑执行；Entity 字段由该实体领域编辑执行；跨域关系先列双方所有者及变更清单。
语义去重不可只凭字符串相似或相同中文译名；没有证据则标需判断，不自动合并/删除。

## 本地统一入口
涉及本地编辑、检查或 Revision 交付时，读取 [fbkb 操作契约](../flipbelt-editorial-chief/references/knowledge-operations.md)；遵循本职责的自动检查与授权边界。
