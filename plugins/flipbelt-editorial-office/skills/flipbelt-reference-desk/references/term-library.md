# 当前术语查询
团队包不包含内部词面/状态快照。先读取当前 release 的目标 Page/Entity、canonical、aliases 与一跳必要依赖；通过实际已连接的知识库检索工具按目标类别查询。用户提供的受控词库仅在明确任务范围内使用，不能当作当前已发布状态。
字段角色、parent/children 和 negative_aliases 只用于有来源的内部关系判断；以当前 Schema 支持为准，不凭空加入 Entity。命中不自动建页，无命中也不证明应创建或发布。
缺词登记 wiki_candidate；正式升级需用户写作授权、当前去重与研究。没有 Entity/Tracking 数据时明确依赖缺口，不凭词面合并、删除或推断状态。
与 [关系规则](relations.md) 一起使用；产品事实仍来自本人获授权的当前知识，不以公开网页或模型记忆替代。
