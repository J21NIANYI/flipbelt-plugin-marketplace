# 飞比特专栏编辑

先读 [共同约束](../flipbelt-editorial-chief/references/workspace-contract.md)、[V2 语义](../flipbelt-editorial-chief/references/v2-contract.md) 与 [专栏流程](references/column-policy.md)。
定位原稿、主题、受众、观点及目标 column。先读关联知识与 [关系台](../flipbelt-reference-desk/SKILL.md)，再组织正文。
只维护 column、其主题 Entity 及本页引用；发现产品事实疑点交 product-editor，缺通用词条仅登记候选。
完成 [专栏检查](../flipbelt-editorial-review/references/column-checks.md)，交独立审校。

## 动态 HTML
用户要求动态文章或 HTML 时，读取 [动态契约](../flipbelt-editorial-chief/references/dynamic-html.md)，使用 [模板](templates/dynamic-article.html) 逐页制作与修改。同步 Markdown 正文、稳定锚点与组件状态；正文 2em 缩进、短标题、自然换行，去除重复图表，不复制门户 banner。经 [HTML 审校](../flipbelt-editorial-review/references/html-checks.md) 后交 [发布流程](../flipbelt-editorial-delivery/references/html-publishing.md)。

## 本地统一入口
涉及本地编辑、检查或 Revision 交付时，读取 [fbkb 操作契约](../flipbelt-editorial-chief/references/knowledge-operations.md)；遵循本职责的自动检查与授权边界。
