# 外部研究与证据门禁

## 何时必须新鲜研究

以下操作只要改变事实性正文、版本状态或来源结论，就必须在当前任务联网核验：

- 创建词条；
- 改写、扩写或事实更新；
- 更新标准版本、品牌所有权、技术状态或研究结论；
- 将候选升级为正式 Page/Entity。

纯目录移动、Reference/关系维护、格式修正和稳定 ID 维护不改变事实时，可不重新研究。

## 来源优先级

1. 标准制定机构、政府/国家标准平台、品牌官方技术资料、原始科研论文、学术或专业组织。
2. 系统综述、共识文件、大学/科研机构、专业运动科学或营养机构。
3. 专业行业媒体和高质量技术媒体，只作补充。

普通博客、电商页、经销商转述、SEO 内容、社交帖子和无署名百科默认不能作为核心证据。

## Claim-level Sufficiency

- 标准：必须有官方标准来源，并核验编号、正式名称、领域、版本、状态和替代关系。
- 品牌与技术平台：主体、技术名称和产品体系必须有官方来源；性能宣称若写成客观结论，需要独立证据或明确标为品牌自述。
- 训练、补给和热生理：涉及强度、剂量、健康或风险边界时，至少有研究/专业机构来源，并尽量用独立来源交叉验证。
- 简单定义：唯一权威来源可单独支撑定义；只要加入机制、效果、比较或建议，就补足相应证据。
- 来源数量不是独立通过条件。两篇低质量文章不能替代一个直接、权威、适用的证据。

## Evidence Matrix

写作前内部形成：

```yaml
claim:
source:
source_level:
scope:
supported:
conflict:
notes:
```

冲突时比较官方性、版本、发布日期、研究对象和适用范围；不能裁决就保留冲突并停止写入该结论。

## 产品与测试边界

- 本地产品资料可以证明 FlipBelt 某产品实际使用了某材料/技术，不能独立证明通用原理。
- 材料、纱线、局部部位或实验室样品数据不得写成整件产品实测。
- 没有阈值时只解释测量值和条件，不写“达标”“领先”或等级。
- 营养、训练和生理内容不是个体医疗处方；不提供无法由来源支持的绝对阈值。

## 失败关闭

- 无法联网或外部来源不可访问：不写事实性正式正文。
- 标准缺少官方确认：失败。
- 品牌技术缺少官方资料：`needs_verification`，留在 Tracking。
- 训练、补给或生理只有低质量内容：`insufficient_evidence`。
