# 参考：可量化的局部编辑

## 意图识别

仅在用户要求精确调整颜色面积、亮度、数量、位置、边缘差值或指定容差，且主体设计必须基本不变时使用。

不要在开放式重构、风格探索或用户只表达“更少、更轻”等主观倾向时使用。

## 测量口径

先区分像素阈值、色域掩膜、对象面积和视觉感知占比。不得把一种口径的结果改名为另一种；口径会改变结果时先确认，否则选择最贴近用户措辞的口径并说明。

## 泛化方法

- 编辑前记录同口径基线，建立目标区域掩膜，并保护构图、纹理和非目标颜色。
- 生成式编辑最多尝试一次；若未进入容差，不再用新提示词追逐百分比。
- 当前工具政策允许时，切换到一次确定性局部调整，并重新测量；不允许时保留候选并报告偏差。
- 同时报告目标指标、测量口径和全图变化范围，不因无缝检查失败丢弃已达到颜色目标的候选。

## 效果判断

精确任务应在同一口径和容差内达到目标，并让非目标区域变化最小。主观视觉任务不强行给出伪精确百分比。
