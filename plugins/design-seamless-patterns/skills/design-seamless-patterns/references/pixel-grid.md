# 参考：像素网格与块面溶解

## 意图识别

仅在用户明确要求像素、方格、马赛克、数字网格、块面聚集或渐隐溶解时使用。

不要在有机流体、手绘笔触、连续自然曲线或非数字化质感中使用。

## 泛化方法

- 让网格在清晰、柔化、聚集、稀疏和溶解之间变化，不生成等密度棋盘格。
- 通过块面尺度、局部亮度和聚集区域建立主次；避免中心放射和四角对称。
- 主辅色通过局部带状、簇状或发光关系出现，不平均交替。
- 控制像素周期与边界相位；若高频网格首次验缝失败，按主 Skill 立即转人工。

## 效果判断

有效结果应保留数字网格识别度，同时具有非均匀节奏；规则棋盘、摩尔纹和明显重复方块属于失败。
