# 参考：字符、文字与交叠

## 意图识别

仅在用户要求字符、数字、符号、品牌词、花体连笔、涂鸦笔触，或强调穿插和遮挡时使用。

不要在纯抽象无文字图案、只需改色或文字必须作为独立排版层时使用。

## 泛化方法

- 先限定允许内容、拼写、是否可组成词语及相对出现频率。
- 区分“散落字符”和“完整文字嵌入线条”；只有用户要求时才生成可读词语。
- 通过大小、位置、旋转、局部裁切和间距变化降低机械重复；频率调整时保持文字不形成规则行列。
- 文字嵌线时让笔画方向、粗细和连接方式服从主线条，不把文字贴在图案表面。
- 增加交叠时控制深色重量并保留安静区域。

## 效果判断

逐个核对拼写、数量和可读性。生成模型可能误写或新增字符；准确文字优先使用允许的确定性排版方法。
