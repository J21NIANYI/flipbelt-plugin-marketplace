# 参考：柔焦流体与渐隐半调

## 意图识别

仅在用户明确要求迷幻、流体、熔融、雾化、柔焦、渗色、色晕、视觉残影，或需要软化硬边和矢量贴片感时使用。

不要在用户要求硬边色块、平涂丝网、清晰几何轮廓、干刷颗粒或无渐变印花时使用。

## 泛化方法

- 保留原图主要运动方向和密度，再增加熔融扭曲、重影、热浪或空间错位；不要默认改变构图骨架。
- 使用较少但尺度更大的连续色域，避免堆积小图标。
- 通过宽幅过渡、色彩渗透和柔化光晕连接边界。
- 让网点大小或密度逐渐变化并溶入邻近色域；根据生产场景控制纹理频率。
- 新增深色或荧光色时限定为局部层次或高亮，不让点缀色夺取主色地位。

## 效果判断

有效结果应由连续运动、边缘过渡和层次错位产生氛围。均匀描边、重复曲线或中心对称通常仍显规则。
