# 参考：方向性运动线条

## 意图识别

仅在用户要求速度感、竞赛能量、纵向/斜向流动、宽窄线层级、提高线条密度或缩小留白时使用。

不要在静态块面、像素网格、散点、细胞斑或以手作色块为主的图案中使用。

## 泛化方法

- 先确定主运动方向，再用少量反向或横向路径形成张力。
- 混合主导宽线、连接中线和少量细线；密度提高时仍保留局部呼吸区。
- 用变宽、收尖、弯折、交叠和跨边路径表达速度，不把所有线做成等宽平行带。
- 渐变只服务于方向和层次，不模糊全部轮廓。
- 文字嵌线需求同时读取 `interwoven-glyphs.md`。

## 效果判断

缩略图应能读出明确动势，2×2 后不形成重复竖栏、横带或密度断层。
