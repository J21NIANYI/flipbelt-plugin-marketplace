# 参考：受控的不规则感

## 意图识别

仅在用户明确要求更凌乱、更自然、更手作、打破规律，或待生成图存在同尺度、等间距、固定方向、均匀撒点等问题时使用。

不要在用户要求几何秩序、规则网格、极简重复、对称构成或仅需改色时使用。

## 泛化方法

- 把“随机”拆成尺度、间距、密度、方向、断裂、重叠与留白的变化。
- 同时安排开放区域和局部聚集，不平均填满画面。
- 改变笔触长度、粗细、压力、边缘、倾斜和成束方式。
- 保留可控的视觉层级；不把不规则误解为无限增加噪点。

## 效果判断

有效结果应减少行列感和预测性，同时仍有主次与呼吸。若只是把元素整体缩小或旋转，通常仍会显得机械。
