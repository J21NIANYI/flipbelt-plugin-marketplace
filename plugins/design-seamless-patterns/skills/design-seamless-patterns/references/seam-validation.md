# 参考：生产级无缝验证

仅在用户明确要求严格验缝、四方连续认证或生产可用交付时读取。

## 共同检查

1. 保存不覆盖原图的视觉候选。
2. 查看单幅、缩略图和首次 2×2 平铺。
3. 检查横缝、竖缝、交点、跨边形状、方向、颜色、纹理密度、网点相位和重复节奏。
4. 分别记录视觉目标、非目标区域保护和无缝状态。

## 方法与预算

- 简单色块和清晰轮廓：允许一次周期偏移、跨边修补、窄带周期融合或局部重绘；修复后执行一次完整复检。
- 复杂密集线条、连续互连曲线、高频网格、精细网点或相位敏感纹理：首次检查失败后立即停止自动处理，转人工精修。
- 禁止水平、垂直、旋转镜像及镜像四宫格拼接；镜像风格也不能成为无缝工程捷径。
- 不用宽羽化掩盖线条、网格或网点周期错误。

## 结果状态

只有边界、交点、纹理相位、重复节奏和非目标区域全部通过时，才能标记为生产可用。失败版本可作为视觉候选交付，但必须标记“无缝检查未通过/需人工精修”。

人工转交时说明需重接的跨边曲线、网格或纹理相位，不限定具体软件。
