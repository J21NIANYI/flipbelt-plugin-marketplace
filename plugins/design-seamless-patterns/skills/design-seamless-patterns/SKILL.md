# Design Seamless Patterns

先识别当前任务，再组织提示词。把视觉设计与无缝验证分开；不要把历史实例的风格、比例、颜色或构图带入无关任务。

## 授权边界

- 默认只生成一个候选稿，不建立评审板，不自动进行多稿评优。
- 只有用户同时明确点名或授权 `Creative Production`，并明确要求多个稿件的比较、筛选或评优时，才调用该插件。仅有设计任务、多张参考图、“提高质量”或“提供方案”等表述均不构成授权。
- 只有用户明确要求 subagent、并行代理或委派多个独立任务时，才创建 subagent。多候选需求本身不构成 subagent 授权。
- 用户明确禁止某个插件、技能或代理时，不调用，并在交付中简要确认。

## 意图路由

仅在用户要求或输入图特征明确匹配时读取对应参考；不得因“都是无缝图案”而加载全部参考。

- 打破均匀、制造手作随机节奏：[controlled-irregularity.md](references/controlled-irregularity.md)
- 柔焦、迷幻、流体或渐隐半调：[soft-fluid-halftone.md](references/soft-fluid-halftone.md)
- 字符层级、文字嵌线、笔触穿插或遮挡：[interwoven-glyphs.md](references/interwoven-glyphs.md)
- 可量化的局部面积、颜色或像素调整：[precision-edit.md](references/precision-edit.md)
- 竞速感、方向性流线、宽窄线密度或运动能量：[directional-linework.md](references/directional-linework.md)
- 像素、方格、马赛克、数字网格或块面溶解：[pixel-grid.md](references/pixel-grid.md)
- 用户明确要求生产级四方连续或严格验缝：[seam-validation.md](references/seam-validation.md)

未命中时不读取参考文件；同时命中时只读取直接相关模块，并以用户当前要求为最高约束。

## 通用流程

1. 查看待生成图、编辑目标和参考图，不仅凭文件名判断。
2. 为每张输入图指定一个主要角色：编辑目标、结构参考、配色参考或质感参考。多张参考图不等于多个设计方向。
3. 提炼本轮唯一目标、必须保留项、禁止改变项和交付状态。每轮只解决一个主要问题。
4. 默认生成一个非破坏性正方形候选稿；只有用户明确要求多稿时才增加数量。
5. 保存视觉候选后按验证模式检查，不覆盖用户原图，不把候选稿误标为生产可用。

## 验证模式

- **探索模式（默认）**：完成视觉目标；2×2 检查用于诊断，候选稿可保存，但不得标记为生产可用。
- **标准模式**：用户明确要求常规验缝或无缝候选交付时使用。执行一次 2×2 检查；简单图案最多允许一次非镜像修复。
- **生产模式**：仅在用户明确要求严格验缝或生产可用认证时使用。读取 `seam-validation.md`；未全部通过不得认证。

复杂密集线条的停止规则适用于所有模式，不能通过切换到探索模式绕过。

## 图像生成与编辑

- 用户只要求提示词、诊断或建议时，不生成图片。
- 用户要求实际生成或编辑位图时，同时遵循 `$imagegen`，使用内置图像生成/编辑能力；不因使用本 Skill 自动启用其他创意插件。
- 新设计为输入图定义结构、配色或质感角色；修改现有图时明确编辑目标，并在每轮重复不变量。
- 精确比例任务先定义测量口径；生成模型不能可靠保证像素比例。

## 提示词结构

只写当前任务需要的字段：

```text
Use case: [新设计 | 风格迁移 | 定向编辑]
Asset type: square four-way seamless repeat tile
Input roles: [逐张定义唯一角色]
Primary request: [本轮唯一目标]
Visual hierarchy: [主次、疏密、尺度、方向、留白]
Palette logic: [主色、辅色、点缀、禁用色]
Material/texture: [当前需要的媒介特征]
Repeat behavior: [跨边元素和四角关系]
Critical invariants: [不可改变项]
Avoid: [最可能出现的失败形态]
```

优先使用相对关系表达视觉目标；只有用户要求可测量结果时才使用数值，并说明测量口径。

## 通用设计原则

- 用尺度、间距、方向、疏密、遮挡和留白建立节奏，避免无依据的平均分布。
- 让部分元素自然跨边，不为了无缝让四边出现同质拥堵。
- 保持无中心、无边框的满版构图；除非用户要求，避免整齐行列和中心徽章。
- 将颜色组织为清晰主次；不要从历史实例继承具体色值或比例。
- 增加复杂度时保护可读层级和安静区域，避免整体变沉、变脏或变碎。
- 禁止使用水平镜像、垂直镜像、旋转镜像或镜像四宫格构造无缝母版，即使用户要求镜像风格，也不得把镜像拼接作为无缝工程方法。

## 无缝验收与停止条件

1. 分开判断“视觉目标是否完成”和“是否通过无缝验证”。
2. 查看单幅、缩略图和首次 2×2 平铺，检查横缝、竖缝、交点、重复方块、密度跳变和纹理相位。
3. 若失败区域涉及复杂密集线条、连续曲线、高频网格、精细网点相位或大量互连细节，立即停止自动处理。不要再次生成、羽化、重采样或拼接，转人工精修。
4. 仅对结构简单、边缘关系清楚的图案执行一次非镜像修复；仍失败则停止并转人工。
5. 像素闭合不等于视觉重复自然；提示词中的 `seamless` 也不是技术证明。

## 人工转交

触发停止条件时标记：`视觉候选稿` / `无缝检查未通过` / `需人工精修`。保留当前稿和首次 2×2 检查结果，说明失败边界、缺陷类型、已完成的视觉目标及人工需重接的线条或纹理；随后结束任务，不继续试验。

## 交付

记录使用的意图模块、是否调用经授权的插件或 subagent，并分别标记：

- `视觉编辑完成/未完成`
- `无缝检查未执行/未通过/通过`
- `候选稿/生产可用/需人工精修`

视觉目标完成但未通过生产级验证时，可以交付候选稿，但必须准确标注状态。
