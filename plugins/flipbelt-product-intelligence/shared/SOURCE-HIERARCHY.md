# Source Hierarchy

## FlipBelt facts

1. 用户在当前任务中的明确修正决定审查对象、季节、市场、版本范围和被审查内容；它不能伪造或改写已发布事实。
2. `flipbelt-kb` 当前激活 release 中目标季节与产品的完整 Product Page。
3. 涉及尺码、逐码口袋、完整规格或身高体重推荐时，同一 `season + product_name` 的完整 Size Guide Page。
4. 涉及品牌、人群、产品线或表达规范时，当前 Brand Base Page。
5. 由目标 Page 明确关联并适用于本次任务的已发布 Reference/Entity Page 或受控 Asset。
6. 如果 MCP 不可用、release 元数据缺失或多次读取不一致，结论为未知并失败关闭。

知识仓 Raw、Tracking、Archive、本地 Legacy、搜索摘要和第三方电商页都不是已发布事实。

## External sources

- 赛事：官方赛事站 > 官方组织方 > 官方管理机构 > 可靠二手来源。
- 材料/研究：正式标准、同行评审论文、政府、大学、权威研究机构 > 专业技术资料。
- 天气：实时天气服务或官方警报；必须标注地点、预报时段和核验时间。

搜索引擎只用于发现页面。关键事实应回到原始或官方页面核验。
