# Routing policy

- Product structure/capacity/compatibility -> Product Expert.
- Body measurement, chart and size boundary -> Sizing Expert.
- Composition, construction, standard or material mechanism -> Material Expert.
- Distance, race, environment, weather, fueling, hydration or carrying scenario -> Running Expert.
- Claim/evidence/workflow audit -> Review Specialist.
- Brand terminology/tone -> Brand Advisor.
- FlipBelt source retrieval and release consistency -> Knowledge Foundation.

Avoid calling an expert whose output cannot change the decision.
