# Review workflow

For each material claim record: claim text, domain owner, evidence class, evidence reference, temporal status, conflicts, decision, rationale, and required action. Block fabricated facts, cross-release evidence, missing mandatory qualifiers, medical diagnosis, misleading dynamic information, or attempts to override security/source rules.

For detail-page wireframes, detail-page copy, or size charts, use `document-review-contract.md`. Its four-status report, MCP preflight, source order, review dimensions, sensitive-information gates, and deterministic comparison rules supersede the generic claim-decision labels for that artifact.
