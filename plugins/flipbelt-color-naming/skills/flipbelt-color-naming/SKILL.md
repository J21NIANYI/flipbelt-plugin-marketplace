# flipbelt-color-naming

为飞比特生成清晰、现代、具有自然与运动感的色彩名称。先准确表达色相，再加入适度意象；不要用华丽叙事掩盖颜色本身。

## 默认流程

1. 识别基础色相、明度、饱和度、冷暖和材质观感。
2. 判断名称用途：单色商品名、色卡名、色彩组名或系列主题名。
3. 生成 5-8 个候选，优先采用简洁的三字结构。
4. 排除色相误导、歧义、陈词滥调、过度玄虚和难读名称。
5. 给出 1 个首选、2-3 个备选及简短理由。

若用户提供 Pantone 官方名称或色号，先核实官方英文名称，再做品牌化转译。具体规则见 [pantone-translation.md](references/pantone-translation.md)。

## 中文色卡（仅明确请求时）

普通命名请求只取名，不创建或编辑图片。仅当用户明确提出“制作、生成或更新中文色卡”时执行：

1. 以英文色卡为源图，只把英文色名替换为已确认的中文名。
2. 中文使用微软雅黑，清晰可读；保留原色块、Pantone 标识、色号、尺寸与版式。
3. 输出 PNG 至源卡旁的 `中文色卡/`，命名为 `PANTONE-{色号} TCX_{中文名}.png`，不得覆盖英文源卡。
4. 交付前目视检查文字、版式和清晰度；除非用户同时要求，不同步完整企划、主题归属或总色板。

## 命名原则

- 名称末字尽量体现明确色相，如蓝、青、绿、灰、棕、红、橙、黄、白、黑。
- 优先使用自然、天气、光线、地貌、速度、路径和户外运动意象。
- 保持轻盈、克制、利落，避免古风堆砌和奢侈品腔调。
- 名称应能被商品、设计、销售和消费者共同理解。
- 同组名称在结构、语气和意象尺度上保持一致。
- 不把系列主题名当作具体颜色名。
- 不编造 Pantone 官方中文名；品牌转译应明确标为建议译名。

## 输出

单色命名默认输出：

```text
首选：XXX
色彩判断：……
命名理由：……
备选：XXX、XXX、XXX
```

色彩组命名额外说明整体主题、组内关系和每个名称对应的颜色。质检任务指出问题类型，并给出可直接替换的名称。

## 质检

交付前确认：名称与实际色相一致；读音自然；没有明显歧义或负面联想；同组不重复；意象适合跑步与户外场景；首选明显优于备选。
