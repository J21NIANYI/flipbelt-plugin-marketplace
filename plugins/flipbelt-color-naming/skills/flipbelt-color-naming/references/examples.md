# 色彩命名示例

示例只用于校准结构和语气，不应直接套用到不匹配的颜色。

## 单色

输入：偏灰、低饱和、带雾感的浅蓝。

输出思路：名称应同时表达清冷、轻雾和蓝色属性。首选可采用“雾 + 光/晨 + 蓝”的简洁结构，避免使用偏绿色的“青”造成误判。

## 色彩组

输入：深蓝、亮橙、岩灰组成的夜跑系列。

输出思路：先建立“夜间路径与安全能见度”的组级叙事，再分别命名。三个名称应共享速度、路径或光线语义，但不要重复同一个前缀。

## 质检

问题名：一个偏黄绿色却以“海蓝”结尾的名称。

判断：色相误导。先把末字调整为“绿”或能准确表达黄绿的词，再决定是否保留海洋意象。

## Pantone

输出时并列展示官方英文名、直译参考和飞比特建议名。不得把品牌建议名描述为 Pantone 官方中文名。
