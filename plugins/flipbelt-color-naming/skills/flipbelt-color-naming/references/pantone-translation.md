# Pantone 名称转译

## 原则

Pantone 色号和官方英文名称是事实来源。中文结果是飞比特品牌化建议译名，除非有可靠来源证明其为官方中文名称。

## 流程

1. 核对色号、色彩体系和官方英文名称。
2. 识别英文名称的核心对象、色相信息和文化联想。
3. 结合实际色值判断直译是否会误导色相。
4. 生成一个准确译名和若干品牌化候选。
5. 明确区分“官方英文名”“直译参考”和“飞比特建议名”。

## 输出格式

```text
Pantone 色号：
官方英文名：
直译参考：
飞比特建议名：
转译依据：
```

## 质量要求

- 不凭色号编造官方名称。
- 不把网络零售商、自媒体或第三方色卡名称当作 Pantone 官方名称。
- 保留原名最重要的颜色或对象线索，但不拘泥逐词直译。
- 当官方名称与视觉色相存在张力时，优先保证商品命名不会误导消费者，并说明取舍。
- 同一项目内相同 Pantone 色号保持译名一致。
