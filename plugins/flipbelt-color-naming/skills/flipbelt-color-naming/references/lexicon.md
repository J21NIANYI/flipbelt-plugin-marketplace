# 飞比特色彩命名词库

按需选词，不要机械拼接。名称首先要准确表达颜色。

## 自然与光线

- 天气：晴、岚、雾、霁、霜、雨、云
- 光线：晨、曦、昼、暮、夜、曜、微光
- 地貌：川、野、原、岭、谷、岸、岩、沙
- 水域：溪、湖、湾、潮、泉、海、涧
- 植物：苔、松、杉、竹、藤、叶、芽、麦

## 运动与路径

- 动势：跃、疾、迅、驰、逐、越、流
- 路径：径、途、轨、线、坡、峰、界
- 体感：轻、清、凉、暖、柔、锐、静

## 推荐色相末字

- 蓝色：蓝、靛、青（仅在实际偏青时）
- 绿色：绿、青、苔、松（后两者需符合具体色感）
- 灰色：灰、银、岩、雾
- 棕色：棕、褐、咖、沙
- 红橙：红、赤、朱、橙
- 黄色：黄、金、麦、柠
- 中性色：白、米、黑、墨

## 高风险用词

慎用“皇家、贵族、女王、奢华、仙境、梦幻、永恒、绝世”等空泛或奢侈品化词语。避免生僻字、过度古风、与实际色相冲突的意象，以及可能引发疾病、灾害、污浊或死亡联想的词。

## 组合建议

优先尝试“意象 + 状态 + 色相”或“时间/地点 + 色相”的三字结构。若两字已经准确有力，不必为了三字结构强行加词。
