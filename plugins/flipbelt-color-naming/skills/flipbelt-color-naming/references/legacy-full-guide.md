# flipbelt-color-naming Skill

## 1. Skill 定位

本 Skill 用于为飞比特跑步服饰、运动装备、色彩企划、商品色卡与系列叙事生成统一风格的颜色名称、色彩组名称与主题命名。

它不是单纯“取一个好听的名字”，而是一套面向品牌资产沉淀的命名系统：

- 以自然户外意象为叙事来源；
- 以跑步运动场景为体验锚点；
- 以商品化传播为落点；
- 以色彩属性判断为底层逻辑；
- 以克制、专业、清爽、有画面感为品牌语气。

适用于：

- 单个颜色命名；
- 一组颜色的命名与分组；
- 季度色彩企划主题命名；
- 波段主题命名；
- 产品色彩故事说明；
- 色名质检与优化。

---

## 2. 核心命名原则

### 2.1 颜色名优先采用“三字结构”

颜色名以三字为主，结构建议为：

```text
自然意象 / 场景意象 + 色相词
```

示例结构：

```text
雾 + 岩 + 灰
湖 + 岸 + 蓝
霜 + 松 + 绿
砂 + 岭 + 棕
晨 + 风 + 白
```

优秀色名应满足：

- 一眼能感知大致色相；
- 有自然场景或户外画面；
- 不过度诗化；
- 不像香水名、民宿名、文旅口号；
- 能出现在吊牌、电商详情页、色卡、企划案中；
- 长期看仍然不尴尬。

---

### 2.2 末字尽量落在明确色相词

颜色名最后一字优先使用明确色相词，便于用户快速识别颜色。

推荐末字：

```text
蓝、绿、灰、棕、红、黄、紫、橙、白、黑、粉、米、卡、褐、青
```

使用建议：

| 色相方向 | 推荐末字 | 说明 |
|---|---|---|
| 蓝色系 | 蓝、青 | 清冷、湖泊、天空、晨雾、冰川、远山 |
| 绿色系 | 绿、青 | 植被、苔藓、松针、山谷、草坡 |
| 灰色系 | 灰、银 | 岩石、雾气、城市清晨、风化地貌 |
| 棕色系 | 棕、褐、卡 | 砂岩、峡谷、泥土、秋冬户外 |
| 红色系 | 红、绯 | 日出、岩壁、珊瑚、热量、赛事感 |
| 黄色系 | 黄、金 | 晨光、沙地、暖阳、补给感 |
| 紫色系 | 紫 | 暮色、山影、冷调夜跑 |
| 白色系 | 白、米 | 雪、风、云、浅沙、轻盈基础色 |
| 黑色系 | 黑、墨 | 夜跑、岩影、硬朗基础色 |

不建议让颜色名完全脱离色相，例如：

```text
山野呼吸
晨雾漫游
风起之地
流光高地
```

这些更像主题名或系列名，不像商品颜色名。

---

### 2.3 命名要有自然意象，但不能虚

自然意象应来自真实可感知的户外环境，而不是泛泛的“高级感”。

推荐意象池：

```text
风、雾、霜、雪、云、雨、晨、暮、夜、光、影
山、岭、谷、峡、坡、岩、石、崖、岸、湖、溪、河、海
砂、砾、土、苔、松、杉、草、藤、叶、原、洲
冰、川、脊、峰、野、径、路、坡、滩、湾
```

优先方向：

- 清晨跑步：晨风、雾岸、薄光、露草；
- 夏季训练：热浪、湖风、浅滩、日光、补给；
- 秋冬跑步：霜岭、岩灰、松影、冷雾、风谷；
- 山地越野：砂岩、峡谷、砾石、苔坡、山脊；
- 城市跑步：桥影、风道、晨雾、柏油、夜光。

避免方向：

- 玄学感：灵、幻、梦、秘、境；
- 过度小清新：奶、甜、糖、桃气、软萌；
- 过度潮牌化：赛博、镭射、机能、暗黑、废土；
- 过度文旅化：天境、秘境、远方、诗和远方；
- 过度户外硬核：战术、军规、荒原求生感。


---

### 2.4 Pantone 官方名称转译为优先依据

当输入中包含 Pantone 色号、Pantone 官方英文名称，或用户明确要求基于 Pantone 命名时，必须将 **Pantone 官方名称作为第一语义锚点**，再转译为飞比特色彩命名体系。

这条规则优先级高于普通自然意象发散。

#### 2.4.1 基本原则

```text
Pantone 官方名称 = 语义源头 / 命名依据
飞比特色名 = 商品化中文转译 / 品牌化表达
```

执行时不能直接凭色相自由造词，而应先判断 Pantone 官方名称本身传达了什么：

- 是自然地貌？如岩石、沙丘、湖泊、森林、冰川；
- 是天气光线？如雾、霜、风暴、晨光、暮色；
- 是植物动物？如苔藓、松针、花卉、浆果；
- 是材料质感？如陶土、金属、矿石、羊毛、纸张；
- 是抽象情绪？如宁静、活力、深邃、柔和；
- 是地域文化？如海岸、沙漠、热带、极地。

然后将其转译为符合飞比特语气的三字色名。

---

#### 2.4.2 严禁编造 Pantone 官方名称

如果用户只提供了 HEX、图片或视觉描述，但没有提供 Pantone 官方英文名，则不能假装知道对应的 Pantone 官方名称。

必须明确标注：

```text
未提供 Pantone 官方名称，本轮仅基于视觉色彩属性进行命名。
```

如果需要基于 Pantone 官方名称命名，应提醒用户补充：

```text
请提供 Pantone 色号或官方英文名，以便进行官方名称转译。
```

如果当前环境支持联网或检索，并且用户要求查证 Pantone 官方名称，则应优先查证来源，再进行命名。不能凭记忆硬配。

---

#### 2.4.3 转译不是直译

Pantone 官方名称需要先做语义拆解，再做品牌化转译。不要简单机翻。

错误方式：

```text
Pantone 官方名：Blue Fog
错误直译：蓝雾色
问题：像翻译词，不像商品色名，也不够飞比特。
```

正确方式：

```text
Pantone 官方名：Blue Fog
语义锚点：蓝色、雾气、低饱和、清晨空气感
飞比特色名方向：雾岸蓝 / 晨雾蓝 / 霜雾蓝
```

转译目标：

- 保留 Pantone 官方名称的核心意象；
- 让中文色名具备明确色相；
- 转成三字商品色名；
- 更接近跑步、自然、户外、轻功能语境；
- 避免生硬翻译腔。

---

#### 2.4.4 Pantone 转译流程

当输入包含 Pantone 官方名称时，必须按以下流程输出：

```text
Step 1：识别 Pantone 色号 / 官方英文名称
Step 2：拆解官方名称的字面含义
Step 3：判断其自然意象、情绪、材质或场景来源
Step 4：结合实际色相、明度、饱和度、冷暖进行校正
Step 5：转译为 5-10 个飞比特三字色名
Step 6：检查是否保留官方名称语义锚点
Step 7：按商品化程度排序
```

如果 Pantone 官方名称与视觉色相存在冲突，例如官方名偏抽象但颜色明显偏绿 / 偏灰 / 偏蓝，则处理原则为：

```text
色相末字优先尊重视觉颜色；
前两字优先承接 Pantone 官方名称的语义。
```

示例：

```text
Pantone 官方名偏“Stone”语义，但视觉明显偏绿：
不应命名为“岩石灰”，可转为“岩苔绿”或“石苔绿”。
```

#### 2.4.6 Pantone 转译质量标准

一个合格的 Pantone 转译色名，必须同时满足：

```text
[ ] 没有脱离 Pantone 官方名称的原始语义；
[ ] 没有生硬直译；
[ ] 末字能体现真实色相；
[ ] 符合飞比特自然户外叙事；
[ ] 适合跑步服饰商品化；
[ ] 不像文旅名、香水名、玄学名；
[ ] 可在色卡、吊牌、电商、企划案中长期使用。
```

不合格情况：

| 问题 | 示例 | 说明 |
|---|---|---|
| 脱离官方名 | 官方名含 Fog，却命名为烈日橙 | 丢失 Pantone 语义来源 |
| 生硬直译 | 蓝雾色、石头灰 | 翻译腔重，不像品牌色名 |
| 色相错误 | 视觉偏绿却命名为灰 | 用户识别成本高 |
| 过度文学化 | 雾中远方 | 不像颜色名 |
| 过度普通 | 浅蓝、深绿 | 没有品牌资产感 |

#### 2.4.7 Pantone 转译示例

以下示例只展示方法，不代表固定标准答案。

| Pantone 官方名称类型 | 官方名语义 | 飞比特转译方向 | 说明 |
|---|---|---|---|
| Blue Fog | 蓝色雾气 | 雾岸蓝 / 晨雾蓝 | 保留雾感，补充跑步清晨场景 |
| Storm Front | 风暴前线 | 风暴灰 / 风岭灰 | 保留天气张力，降低硬核感 |
| Desert Sage | 沙漠鼠尾草 | 沙 sage 不宜直译，可转为砂谷绿 / 旷砂绿 | 保留沙漠与灰绿草本感 |
| Ice Flow | 冰流 / 浮冰 | 冰川蓝 / 冰流蓝 | 保留冷感与流动感 |
| Moon Rock | 月岩 | 月岩灰 / 岩月灰 | 保留岩石与冷灰质感 |
| Sunlit Allium | 日光葱花紫 | 日葱紫不适合，可转为光穗紫 / 晨光紫 | 保留日光与植物色感，避免直译尴尬 |

#### 2.4.8 内部命名优先级

当多个命名依据同时存在时，优先级如下：

```text
1. Pantone 官方英文名称与色号
2. 真实视觉色相、明度、饱和度、冷暖
3. 飞比特季度主题与波段叙事
4. 产品品类与使用场景
5. 自然户外意象发散
6. 传播记忆点与商品化优化
```

也就是说：

- Pantone 官方名称决定“从哪里来”；
- 视觉色相决定“最后叫什么色”；
- 飞比特语气决定“怎么说才像品牌自己的话”。

## 3. 品牌语气

### 3.1 推荐气质

本项目颜色命名应保持以下气质：

```text
专业、清爽、克制、轻功能、自然、户外、运动、干净、有画面感
```

适合表达为：

- 轻户外，而不是硬户外；
- 专业跑步，而不是泛运动；
- 诗意自然，但不能空；
- 有品牌审美，但不自嗨；
- 有传播力，但不网红化。

---

### 3.2 不推荐气质

避免以下命名倾向：

```text
过甜、过潮、过玄、过装、过硬核、过古风、过文旅、过香水、过瑜伽、过奢侈品
```

典型问题：

| 问题类型 | 反例 | 问题说明 |
|---|---|---|
| 不像颜色名 | 春风为证 | 更像系列主题 |
| 太文旅 | 云上秘境 | 像景区宣传语 |
| 太香水 | 雨后呢喃 | 过度情绪化 |
| 太玄学 | 灵境幻蓝 | 不够运动，不够商品化 |
| 太普通 | 浅蓝、深灰 | 缺少品牌资产感 |
| 太网红 | 奶霜白、桃气粉 | 偏小红书甜品感 |
| 太硬核 | 战术岩黑 | 偏军警/机能风 |

## 4. 命名工作流

每次执行命名任务时，必须按以下流程推导，而不是直接发散。

### Step 1：识别颜色基础属性

先判断颜色的基础视觉属性：

```text
色相：蓝 / 绿 / 灰 / 棕 / 红 / 黄 / 紫 / 白 / 黑 / 橙 / 粉
明度：高 / 中 / 低
饱和度：高 / 中 / 低
冷暖：冷 / 中性 / 暖
灰度：清透 / 灰化 / 浊色 / 深沉
材质感：哑光 / 亮感 / 粉感 / 金属感 / 棉感 / 户外感
```

输出前必须先在内部完成判断。

示例：

```text
颜色：低饱和偏灰蓝
属性：冷调、中明度、低饱和、雾感、清晨感
适合意象：晨雾、湖岸、远山、风、浅云
命名方向：雾岸蓝、远山蓝、晨雾蓝
```

---

### Step 2：匹配自然意象

根据色彩属性匹配自然意象。

| 色彩属性 | 推荐意象 | 命名方向 |
|---|---|---|
| 冷灰蓝 | 雾、湖、远山、冰、晨光 | 雾岸蓝、冰湖蓝、远山蓝 |
| 深海军蓝 | 夜、山影、冰川、冷风 | 夜脊蓝、冰川蓝、山影蓝 |
| 灰绿色 | 苔、松、山谷、草坡 | 苔谷绿、霜松绿、山径绿 |
| 暖棕色 | 砂岩、峡谷、土坡、砾石 | 砂岭棕、岩谷棕、砾石棕 |
| 浅米白 | 浅沙、晨雾、云、雪 | 浅砂白、晨雾白、云岩白 |
| 暖红色 | 日出、岩壁、珊瑚、热量 | 岩阳红、珊瑚红、晨焰红 |
| 亮黄色 | 晨光、补给、日照、旷野 | 晨光黄、旷野黄、日砂黄 |
| 暮紫色 | 暮色、山影、冷夜、云层 | 暮岭紫、夜雾紫、山影紫 |
| 深黑色 | 夜、墨、岩影、风道 | 夜岩黑、风道黑、墨岩黑 |

---

### Step 3：判断使用场景

同一个颜色在不同场景里，命名方向应不同。

| 使用场景 | 命名策略 |
|---|---|
| 春夏跑步 | 更轻、更清透，使用风、晨、湖、岸、光 |
| 夏季高温训练 | 更有能量，使用热、浪、日、砂、橙、黄 |
| 秋冬跑步 | 更冷静，使用霜、雾、岩、松、谷、夜 |
| 越野 / 山地 | 更地貌化，使用峡、砾、岩、坡、脊、砂 |
| 基础常青色 | 更稳定，使用岩、墨、云、雾、石、松 |
| 高可视色 | 更直接，但避免廉价荧光感，可用光、焰、日、能量意象 |

---

### Step 4：生成候选名

每次至少生成 5 个候选名，建议覆盖以下层级：

1. 最稳妥商品化方向；
2. 最有自然画面方向；
3. 最运动功能方向；
4. 最高级克制方向；
5. 最具传播记忆方向。

候选名不应全部使用同一意象，避免“雾蓝、晨雾蓝、山雾蓝、湖雾蓝”这种低质量堆叠。

---

### Step 5：质检与排序

每个候选名需要从以下维度打分或判断：

| 维度 | 判断问题 |
|---|---|
| 色相识别 | 用户能否从名字判断大致颜色？ |
| 自然画面 | 是否有清晰自然/户外画面？ |
| 跑步关联 | 是否适合跑步服饰，而不是泛生活方式？ |
| 商品化 | 是否适合吊牌、电商、色卡？ |
| 长期性 | 3 年后看是否仍然成立？ |
| 传播性 | 是否好读、好记、不拗口？ |
| 风险 | 是否有误读、俗气、撞名、过度诗化？ |

当用户提供已有色名并要求判断时，输出：

```markdown
| 原色名 | 判断 | 问题 | 优化方向 | 推荐替代 |
|---|---|---|---|---|
|  | 可用 / 可优化 / 不建议 |  |  |  |
```

判断标准：

```text
可用：符合色相识别、自然意象、商品化、品牌气质。
可优化：方向正确，但存在拗口、过虚、过普通或不够色彩化的问题。
不建议：不像颜色名、过度诗化、太俗、误读风险高或不符合运动品牌语气。
```

## 6. 系列名与颜色名的区分

### 6.1 颜色名

颜色名用于具体商品颜色，应短、清晰、可识别色相。

示例：

```text
雾岸蓝
霜松绿
岩谷棕
浅砂白
夜岩黑
```

### 6.2 系列名 / 波段名

系列名可以更有叙事感，不强制末字为色相。

示例：

```text
春风为证
热浪为盟
高地流光
疾风知劲草
```

### 6.3 判断原则

如果一个名字回答的是“这是什么颜色”，它就是颜色名。

如果一个名字回答的是“这一季讲什么故事”，它就是系列名。

不要把系列名直接当颜色名使用。

## 9. 质量评分标准

每个色名可以按 5 分制评分。

| 维度 | 5 分标准 | 3 分标准 | 1 分标准 |
|---|---|---|---|
| 色相识别 | 能快速判断颜色 | 色相模糊但可联想 | 完全不像颜色 |
| 自然画面 | 画面清晰且不俗 | 有画面但普通 | 空泛或俗气 |
| 品牌适配 | 很适合跑步服饰 | 泛运动可用 | 不适合运动品牌 |
| 商品化 | 吊牌、电商、企划均可用 | 需要解释 | 不适合作为商品色名 |
| 长期性 | 3 年后仍成立 | 有轻微流行感 | 明显短期网红词 |
| 读感 | 顺口、好记 | 略拗口 | 难读或尴尬 |

推荐使用总分 24 分以上的色名。

低于 18 分的色名不建议进入色卡系统。

## 11. 最终输出风格要求

回答时应：

- 直接给结论，不绕；
- 先判断，再命名；
- 多给可执行建议，少给空泛赞美；
- 对不合适的名字明确指出问题；
- 保持鼓励，但不为了好听而放水；
- 输出结构清晰，方便复制进企划案、表格或色卡系统。

不应：

- 只给一堆名字不解释；
- 过度发散，生成大量无法使用的文学化名字；
- 用“高级、自然、有质感”这类空话替代判断；
- 把系列主题名和商品色名混为一谈；
- 无视色相，生成看不出颜色的名字。
